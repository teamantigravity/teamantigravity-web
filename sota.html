SOTA is a token-driven, component-slot, behavior-layer design system for building award-winning product websites. It ships with no cloud, no sign-ups, and no telemetry — the same privacy-first philosophy that powers every Team Antigravity app.

Get SOTA See how it works
01 · Design tokens

A single source of truth for every value

Colors, typography, spacing, motion, elevation, and radius are defined as tokens once and reused everywhere. Swap a product accent or a whole theme by overriding a JSON file — no component rewrite required.

02 · Component slots

Content-agnostic shells that adapt to any product

Hero, feature, data, and CTA sections are built as shells with named media, content, and decoration slots. Drop in new copy, images, or 3D models from a CMS and the layout stays consistent.

03 · Behavior layers

Motion and interaction decoupled from UI

Animations are registered as named presets and applied via data attributes. Designers can toggle presets, adjust stagger timing, and respect reduced motion without touching the markup.

04 · Device tiers

From flagship desktop to low-end mobile, gracefully

Hardware capability scoring maps every device to Full, Balanced, or Lite tiers. 3D models, particles, and parallax scale back automatically so the experience stays smooth at 60fps.

Why we built it this way

Three rules we don't break.

60fps or nothing

Every animation, 3D scene, and scroll effect is budgeted and benchmarked. If it can't hold 60fps on real devices, it doesn't ship.

Privacy is the default

No accounts, no tracking pixels, no analytics capture, no server-side data collection. The design system itself doesn't phone home.

Adapt, don't rebuild

Tokens, slots, and behavior layers make the next product, campaign, or locale a configuration change rather than a redesign.
